# ABBA / fABBA / QABBA Benchmark binding

Consumption of `abba-family-20261020-v1.tar.gz`, SHA-256 `ec70b59fd9e0a48303604596df43fa8e21090b6f577513f11894e727a6240b1e`. `FROZEN_SOURCES.json` records exact release members; no algorithm/dependency source edits. Build runs Autotools on a private source copy. `native/binding.cc` is the only new native implementation here.

`abba`, `fabba`, `qabba` replace the old ABBA/FABB code and use complete AFS1 frames. Native core supports rank1 binary64, owned encode/decode results. C1/object mode accepts rank1/2, independent column fitting, column-major staged input (AFI1). One column produces the original AFS1. Multiple columns produce AFM1: magic, u32 version=1, u64 rows, u64 columns, then [u64 frame length, complete AFS1] for each column, followed by CRC32 of the entire prefix. All integers are little endian; all serialized bytes are charged. Neither decoder needs encoder parameters, files or a fitted object. A shape mismatch, cross-algorithm frame or trailing bytes fails.

Limits: finite binary64, 2..1,048,576 rows, <=4096 columns, <=1,048,576 total values; combined frame <=256MiB. Released numerical/work/codebook limits also apply. Only `empirical_quality` is supported. Source reconstruction can change the number of samples; such objects are rejected before committing output. Encoder performs a timed complete recovery check to enforce that predicate; the released encoder itself also computes the source fit reconstruction. No work is cached outside clocks. The bound is conservative size arithmetic without fitting. Core output is owned; C1 stages output and commits once, permitting atomic capacity retry.

ABBA `compression_tolerance`/`digitization_tolerance` map to the source `tol` pair, `clustering` to `c_method`, seed is fixed true; min_k=1 is the explicit Bench default (standalone source default is 2). fABBA `tolerance` maps to `tol`, alpha default is now 0.5, all five sorts and both diagnostic backend semantics execute in C++. QABBA `tolerance` maps to `tol`, digitizer agg/kmeans/f-kmeans, norm/pca sorting, widths1..64, and nine non-context symbol codecs are exposed. Workers are fixed at one. Source model reuse, shared multi-series fitting, missing filling, images, custom alphabets, unseeded ABBA and context Huffman1 are not Bench capabilities in this revision. Source BIC/KMeans and quantization semantics are preserved, including QABBA frequency remapping.

Numerical environment: little-endian Linux binary64 FE_TONEAREST, C++17, no fast-math, contraction off. Unknown parameters rejected. Binary exports only `tscb_*`/`tsbench_core_*`; all bundled byte codecs and CKmeans are statically linked with local visibility and cannot interpose other codecs.

Licensing is per component: MIT/BSD rewrite, **LGPL >=3 CKmeans ancestry**, zlib, Zstd, bzip2 and XZ notices. All component source, local upstream safety patches, full LGPL/GPL texts and reproducible build recipe are retained for inspection/relinking. Do not label the combined library MIT-only.
